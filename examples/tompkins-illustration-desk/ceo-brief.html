Carrier illustrations

Advisors ask once. Software prepares the three-carrier comparison.

To compare carriers for a client, an advisor runs each carrier’s illustration tool separately and assembles the results by hand. We propose software that does that work and hands back a finished comparison, built from the carriers’ own documents.

How it would work

1RequestThe advisor picks the client, the type of policy and the amount.
2Carrier toolsSoftware fills in each carrier’s tool and saves the carrier’s document.
3CheckEach document is compared with the request. Mismatches go to staff.
4ComparisonThe advisor receives it with the carrier documents, and reviews it.

What changes for an advisor

Today, as we understand it

  • Signs in to three carrier tools
  • Types the same client three times
  • Builds the comparison by hand

With this

  • Makes one request
  • Types the client once
  • Reviews a finished comparison

Where it stands

Not built.
Not yet tested.

Known to work

  • Software filling in a website and saving the PDF
  • Reading figures out of a PDF
  • Building the branded comparison

Not yet known

  • Whether each carrier’s tool can be run this way
  • How long a run takes
  • Whether sign-in still needs a person
  • How much upkeep it needs

The main risk

Carrier rules generally do not allow software to operate their tools. Each carrier would have to agree. If one says no, staff run that carrier’s tool and the software still builds the comparison.

Decision neededApprove a test with one carrier.One advisor, one real case, to see if it works before anything is built. Plus approval to ask the carriers.
