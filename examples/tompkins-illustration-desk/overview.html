Step by step

What happens after the advisor clicks the button

  1. 1

    The advisor asks Advisor · 1 minute

    They open the client, pick the type of case and enter the amount. The client’s details are already there.

  2. 2

    The request is put into each carrier’s language System

    Every carrier asks for the same facts differently. The system converts the request, using rules our best case designer sets once.

  3. 3

    Each carrier’s software produces the illustration System + Claude

    The system signs in and fills in each tool the way a person would. The carrier does the calculating. If a screen changes, Claude, our AI, finishes the job.

  4. 4

    The system checks its own work System

    It confirms each carrier document matches what was asked. Anything that does not match is held back for back office.

  5. 5

    The comparison is delivered System, then advisor reviews

    One Tompkins-branded comparison arrives with the three carrier originals, and a copy goes to the client’s file.

The numbers are the carriers’The system never works out a client figure itself.
People stay in chargeThe advisor reviews everything before a client sees it.
Carriers must agreeEach carrier’s permission is needed before launch.

Times are targets. This is a proposal and has not yet been tested against the carrier tools.
