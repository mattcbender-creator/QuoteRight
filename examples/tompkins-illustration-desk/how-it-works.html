Tompkins Insurance
How it works

One request in. Every carrier’s illustration back.

Think of it as a fast, careful assistant who knows every carrier’s software. The advisor asks once. The assistant runs each carrier’s tool, checks the results and hands back a finished comparison.

Step by step

What happens after the advisor clicks the button

Followed through one example: a 52-year-old business owner who needs $10 million of permanent coverage.

  1. 1

    The advisor asks

    They open the client’s record, pick the type of case and enter the amount. The client’s details are already there, so nothing is typed twice.

    Example: “Estate preservation, $10 million, compare Canada Life, Manulife and Sun Life.”
    Advisor
    About a minute
  2. 2

    The request is put into each carrier’s language

    Every carrier asks for the same facts in a different way and has its own product rules. The system converts the one request into the exact answers each carrier’s software expects.

    How it knows: the firm’s most experienced case designer sets these rules once, and every advisor benefits.
    System
    Instant
  3. 3

    Each carrier’s own software produces the illustration

    On a secure firm computer, the system signs in to each carrier’s illustration tool and fills it in the way a person would, then saves the carrier’s official document. The carrier does the calculating, so the figures are current and theirs.

    If a carrier changes its screens: Claude, the firm’s AI, reads the new screen and finishes the job. If that fails, a back-office person completes it.
    System + Claude
    A few minutes for all three
  4. 4

    The system checks its own work

    It reads each carrier document and confirms the age, amount and plan match what the advisor asked for. Anything that does not match is held back and sent to back office.

    System
    Seconds
  5. 5

    The comparison is built and delivered

    The figures are lifted from the carrier documents into one Tompkins-branded comparison. The advisor receives it with the three originals attached, and a copy is saved to the client’s file.

    To change it: the advisor replies “rerun at $7.5 million” and the same steps repeat.
    System
    Then the advisor reviews it
The numbers are the carriers’The system never works out a client figure itself. It only operates the carriers’ tools and reads their documents.
People stay in chargeThe advisor reviews everything before a client sees it. Back office handles anything unusual.
It needs the carriers’ permissionRunning their tools this way has to be agreed with each carrier before launch.

Times are targets. This is a proposal and has not yet been tested against the carrier tools. The example client is fictional.
